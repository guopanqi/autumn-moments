# V0.6c — Sunny Pasture / 最小牧场切片

**状态：候选代码已整合到主线，GitHub 验证与人工视觉验收分别记录。**

## 要回答的体验问题

牧场不应只给玩家第二个“摸狗得心情”按钮。首次版本验证一个可观察、需要穿过空间的循环：

采集一束青草 → 走向食槽照料奶牛 → 观察奶牛低头进食 → 等待几秒 → 从奶桶收取牛奶（+8 金币）→ 回家购买/摆放家具。

玩家可以暂时离开、不喂牛。没有失败惩罚、复杂饲料库存或时间驱动的经济压力。

## Scope

- 一个新 `Location`：`farm`，小型开放牧场、有路、谷仓、围栏、一头奶牛、青草地和奶桶。和原有公园、家共用镜头/寻路/角色/动作。
- 一束可携带青草：非背包；只能持有 0 或 1。动物吃饱时无需重复喂食。
- 奶牛在原地呼吸、摆尾、看向玩家，饱食后低头吃草；不是完整自主动物导航。
- 6 秒活动场景内等待之后，出现一桶可收取的牛奶。一次只收一次，结算 8 金币。
- 状态存储为 v3 存档中一个可选 `farmCare` 子对象，兼容旧 v1/v2/v3。当前地点以外不模拟时间（明确技术限制）。
- 无新资产下载和 Blender；不加入大型牧场、种植、成长、养殖繁殖或框架。

## 验证

- 新增 Playwright 测试：地点进入/刷新/返回；动作 cue 之前取消不生效；未采草不能喂；喂食启动计时；恰好一次牛奶奖励；迁移与异常状态归一化。
- 需要在仓库 CodeSpace / GitHub PR CI 完整执行 `npm run build`, `npm run test:smoke`。仅由本地语法/状态测试不足以证明 WebGL 场景正常。
- 人工重点：牧场和公园风格是否连贯、进出地图与小道是否清楚、触摸是否能选中青草/奶桶、奶牛是否有生命感以及多场所积累是否让用户愿意再次回来。

## 此切片的刻意欠账

- 奶牛不在背景离线觅食，6 秒等待只在牧场活动时递减。
- 牛奶直接换成 8 金币，是暂时的经济连接，不代表成熟的生产/运输/出售系统。
- 没有种植、饲料背包、多个动物或复杂 NPC 智能。
