# External asset register

| Asset | Source | License | Used now? | Notes |
|---|---|---|---|---|
| First-party procedural meshes | `src/` | Project-owned | Yes | No external model downloads |
| Three.js | https://threejs.org | MIT | Yes | npm library, not 3D art asset |
| Noto Sans SC font | Google Fonts | SIL OFL | Optional | Loaded as CSS web font with system fallback; inspect privacy/performance before release |

Do not add model, texture, sound or sprite files without documenting their actual source and license. Suggested future candidates (not imported): Kenney CC0 assets and self-authored `.glb` models.
